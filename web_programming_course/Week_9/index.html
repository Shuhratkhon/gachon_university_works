WEEK 09 · WEB ACCESSIBILITY

Accessibility audit of my own course pages

I went back through every HTML page I made for this course (Week 1 to Week 8) and checked the basic things a screen reader, a phone and a keyboard user need. Here is what I found and how each problem gets fixed.

122pages checked
102no <main>
84no viewport tag
66no <title>
27no lang
0images without alt

WHAT I CHECKED

Results by week

My early weeks are the worst. In Week 2 most files were just pieces of HTML without <html> or <head>, so they are missing almost everything. Week 5 and Week 8 pass all four checks.

HOW TO FIX IT

Problem → fix

Click a problem to see why it matters and the code change, using real files from my repo.

Without a title the browser tab just shows the file name, and a screen reader has nothing to announce when the page opens.

BEFORE · Week_3/exercise-2.html 
<head>
  <meta charset="UTF-8">
  <link rel="stylesheet" href="style.css">
AFTER 
<head>
  <meta charset="UTF-8">
  <title>Exercise 2 | Week 3</title>
  <link rel="stylesheet" href="style.css">

A screen reader uses the lang attribute to pick the right voice and pronunciation. Most of these are the Week 2 files that start straight with a tag, so the fix is to make them full documents.

BEFORE · Week_2/exercise-3.html 
<header>
  <nav aria-label="Main navigation">
    ...
AFTER 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Exercise 3 | Week 2</title>
</head>
<body>
  <header>
    <nav aria-label="Main navigation">
    ...

Without it a phone renders the page like a 980px desktop and zooms out, so the text is tiny and people have to pinch to read it.

BEFORE 
<head>
  <meta charset="UTF-8">
  <title>...</title>
AFTER 
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>...</title>

Screen reader users can jump straight to the main landmark. If there is none they have to go through the page from the top every time.

BEFORE · Week_1/exercise-1.html 
<body>
  <h1>Hello, Gachon!</h1>
</body>
AFTER 
<body>
  <main>
    <h1>Hello, Gachon!</h1>
  </main>
</body>
